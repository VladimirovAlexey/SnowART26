# SnowART26
Tables and results of the SNOW26 global fit to twist-3 PDFs.

This repository contains various tables and figures produces in the fit of genuine twist-3 PDF, together with Sivers and wgt TMDPDFs. Each folder has "Content.txt" file with description of the conent. Particularly:
>> 1Dplots = tables of various 1D plots and data (such as g2 function, slices of TMDs, etc)
>> Figures = collections of figures produces in this study (some of them are included into the publication)
>> TMDgrids = collection of grids for TMD  distributions (Sivers and WGT) in the LHA/TMDlib format. These grids are too large to store in github, please, contact us if you need them.
>> Tw3grids = grids of genuine twist-3 distributions

If you use the data from this repository, please, cite the original publication. If you have any questions, please, contact us (Alexey Vladimirov or Guillermo Portela)
